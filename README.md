# Streamlining-IT-Procurement-Automating-Standard-Laptop-Orders-with-Flow-Designer
The Standard Laptop Task flow automates the creation of a Catalog Task for Standard Laptop requests. Once the request reaches the configured approval condition, the flow creates a task under the related Requested Item and assigns it to the Hardware assignment group for laptop configuration.

Purpose: To reduce manual task creation, improve processing speed, and ensure approved laptop requests are automatically routed to the appropriate team.

The Flow Assignment configuration connects the Standard Laptop Service Catalog item with the Standard Laptop Task Flow Designer flow. This ensures that the defined automation is executed for the catalog request and the required configuration task is created and assigned to the Hardware team.

By automating the standard laptop procurement process with ServiceNow's Flow Designer, the project effectively addresses inefficiencies and reduces manual overhead. This streamlined workflow ensures timely configuration of laptops, minimizes user wait times, and enhances overall productivity within the IT department. The implementation of this automated solution not only optimizes resource allocation but also significantly improves the user experience by providing a seamless and efficient procurement process.
